# Evaluation artefacts

- `assistant_baseline.jsonl` — answers produced by the coding assistant for a private
  side-by-side comparison. Every row is labelled `ASSISTANT BASELINE (not Groq)` in
  `reasoning_trace`. **This file is not an agent submission.**
- `gaia_groq_run.jsonl` — the real Groq agent output generated by `make_jsonl.py`
  (added once a full run completes). This is the file intended for submission.
